## 9 October 2026 — Benchmark set-up for exp01 (matched to Cevaal, de Jong and Lazar, 2026)

- **Equation.** Standard Van der Pol: dx2/dt = mu (1 - x1^2) x2 - x1 + u, mu = 1. Cevaal et al.'s Equation 31 (as printed in the HTML version of arXiv:2604.13857v2) and our earlier brief both omit "- x1". Checked numerically: with the printed form and their multisine input (peak 15), the forward-Euler simulation blows up within 211 to 950 steps in every one of 10 trials; even without input it has no limit cycle. With "- x1" it stays finite (|x1| at most 3.2). Their stated limit-cycle behaviour only exists with "- x1", so we treat the omission as a typo.
- **Time step 0.1, forward Euler** — as Cevaal et al. a02 shows the true system's own 50-step error amplification at this step is up to 5.2 (median 2.25).
- **Input.** Multisine, 30 harmonics from 0.0049 to 4.88 hertz, random phases, peak 15 (Cevaal et al.). Harmonic spacing is not stated in their paper; **linear spacing** chosen because logarithmic spacing with peak 15 blows up the Euler simulation in 4 of 5 trials (too much low-frequency energy).
- **Data.** 40,000 training samples (Cevaal et al.), 10,000 validation, 10,000 test, each its own trajectory with its own phases and initial state drawn from x1 in [-2.5, 2.5], x2 in [-2.0, 2.0] (their evaluation range). Data fixed across model seeds (data_seed 12345).
- **Windows.** 10 context steps (true states, to warm up the memory) + 50 prediction steps, stride 5. Cevaal et al. predict 10 steps; we report error at step 10 as well so results stay comparable.
- **Training.** Adam, learning rate 1e-3, weight decay 1e-5 (Cevaal et al.), not applied to decay parameters, biases or normalisation weights; learning rate times 0.97 per epoch; gradient clipping at 1.0; 40 epochs (first attempt: curves flat by 30–50; Cevaal et al.'s 4,000 epochs is far beyond our budget); model with the lowest validation loss is evaluated.
- **Sizes.** Full Mamba: model dimension 8, state 8, kernel 10, 6 layers (Cevaal et al.), expansion 1 (not reported by them) → 3,282 parameters (−4.0% from 3,418). Long Short-Term Memory network: hidden size 25 → 3,152 (+3.3% from 3,052). Minimal cell: width 32, state 16 → 2,850 (mechanism model; no published reference).
- **Model input** at every step is [x1, x2, u, mask]; the mask marks empty state slots in direct multi-step prediction. All three regimes use the same network and the same residual readout x_{t+1} = x_t + W_out y_t.
- **Direct multi-step regime** (our version of Cevaal et al.'s design): after the context, the network sees only future inputs; the readout increments are summed to give the trajectory, and predictions are never fed back. Under this regime the augmented-Jacobian leak of a01 cannot occur, so it is the regime where the latent certificate should matter most.
- **Unstable start.** Decay values mirrored to +1 … +16 (scale 1.0). Mathematical signal: non-finite loss from the first batch (exp(1.6 × 60) exceeds the float32 range), so this arm is expected to diverge in every regime; it is kept because it is declared in the plan.
- **Primary metric.** Root-mean-square error averaged over the 50 prediction steps, physical units, both state components (`rollout_rmse`). Next-step error = error at prediction step 1 in the same regime. Diverged runs are reported as counts.
- **Decision rule for exp01.** Ablation rule (any trained ablation arm more than 20% from its baseline in the same training regime). Blown-up arms are reported as counts and do not count towards "worth confirming". For a null result at Stage 2, the free-sign / certified error ratio must have its bootstrap 95% interval inside [0.9, 1.1] (plan.md, Step 7N).
- **exp01b** runs the same ablation on the full Mamba architecture as a separate experiment, so the minimal-cell result can be read before spending the longer full-Mamba time.

## 18 October 2026 — Learning-rate check (exp01c) before the eight-seed closing run (exp01d)

- **Why.** exp01b (seed 0) put the full Mamba clearly behind the Long Short-Term Memory network in all three training methods and behind the simplified Mamba under chained training (0.465 against 0.256). Its chained validation loss was about twice its training loss and noisy (0.040 to 0.063 over the last six epochs); the other two networks showed no such gap. A learning rate chosen for a different network (Cevaal et al., 0.001) is the cheapest explanation to rule out before any comparison with the Long Short-Term Memory network is relied on.
- **Design (fixed before any result).** Learning rates 0.0001, 0.0003, 0.001 for both the full Mamba (certified decay) and the Long Short-Term Memory network, chained training only, seed 0. Edge of grid: no value above 0.001 is tested because the evidence points downwards; the picker reports when the best value sits at the edge. Forty epochs and a decay of 0.97 per epoch as everywhere else.
- **Rule (fixed before any result).** Score = lowest validation loss over all epochs (the epoch that `train.py` keeps), not the test error, so the choice does not look at the number the paper reports. Scores within 3% count as tied; in a tie the already-used 0.001 is kept, otherwise the tied value closest to it. The Mamba value is chosen on the certified (guarantee-on) arm only and used for the guarantee-removed arm too, so the check cannot favour the arm being tested. Applied by `tools/pick_learning_rate.py`, which writes the number into `configs/models/mamba_full_final.yaml` and `lstm_final.yaml` (once; it refuses to overwrite).
- **Closing run.** exp01d: seeds 0 to 7, certified against free-sign decay, three training methods, plus the Long Short-Term Memory network as a reference. The chosen learning rate applies to every training method of a network (it is chosen from chained training, the method the controller uses). Null-result rule unchanged from exp01b: the free-sign / certified error ratio must have its bootstrap 95% interval inside [0.90, 1.10] to say "no more than 10% difference"; otherwise the wording is "no difference detected" or "the guarantee changes the error". A null result goes to the eight-seed stage on purpose: a paper claim of "no difference" has to be shown, not assumed (plan.md, Step 7N). The 95% interval is stricter than the usual 90% interval of the two one-sided tests procedure for equivalence.
- **Single seed first (added the same day, before any result).** Kaggle session time is limited, so the closing run goes on seed 0 only and shows direction only; the eight-seed run (same config, `--seeds 0 1 2 3 4 5 6 7`) is still required before the paper claim. To save about 31 minutes, the two runs at learning rate 0.001 (full Mamba `certified_chained` from exp01b, Long Short-Term Memory network `lstm_chained` from exp01, both seed 0, identical settings) are not repeated: their `train_log.csv` and `metrics.json` are kept in `docs/evidence/exp01c_reused_runs/` and read by the picker. Only the four new learning-rate runs are trained (`--arms`). The rule and the grid are unchanged.
- **Outcome (18 October 2026).** Rule applied by the picker: 0.001 for both the full Mamba and the Long Short-Term Memory network (no ties; the best value is the highest tested, so nothing above 0.001 was tried). Written into `configs/models/mamba_full_final.yaml` and `lstm_final.yaml` and committed, so the eight-seed run needs no further check. Not widened afterwards: adding 0.003 now would be a change made after seeing the edge-of-grid result; if wanted it must be declared as a new, separate check.
- **Literature checked.** Equivalence testing: the margin must be fixed before data collection and equivalence is concluded only if the interval lies inside the margin (two one-sided tests). The Mamba paper's training appendix (Appendix E.2) could not be retrieved in this session, so no published recipe was used to pick the grid.

## 19 October 2026 — Stage 2 diagnosis: how the four questions are measured (fixed before any result)

- **Models.** The Kaggle session holding the Stage 1 models was lost; exp01d (seed 0) and the six simplified-Mamba arms of exp01 (seed 0, without the "unstable start" arms) were retrained on a T4. The summaries reproduced Stage 1 (guarantee removed: +2%, +4%, +0%). The fifteen final checkpoints (704 KB in total) are now in `models/seed0/`, re-allowed in `.gitignore`, so Stage 2 runs on any processor.
- **Q1 direction of motion** = central difference of the true trajectory at each predicted step (works with the input switched on). Rule on the plain split along / across that direction, as the plan says. A cross-check that also works for large errors (slide each prediction along the true path in time, within 30 steps, less than half a loop) is recorded but not used by the rule.
- **Q2** uses teacher-forced one-step predictions at the same 50 positions as the chained ones. Also recorded: the same one-step errors carried by the true system's own Jacobians (what a perfect feedback loop would do). Not applicable to direct prediction, which feeds nothing back.
- **Q3 sign test** in physical units, as the plan words it; the time-unit version (one-step lag, implied clock speed) is recorded. Both curve fits have two numbers, so the comparison is fair. Direct prediction gets the curve shape only (no one-step errors).
- **Q4** had no rule in the plan; added before any result: shape-push ratio (model's across part after 50 steps / true system's) ≤ 3 corrects, ≥ 10 does not, in between partly. Measured across each one's own direction of motion, because a push across the path turns partly into a timing shift in the true system too (so the total size would mislead). Points on the zero-input loop, so the numbers compare with a02's multipliers (1 along, 0.00086 per loop across).
- **Recorded only (Pervez and Locatello, 2026):** largest error magnification over the horizon, model against the true system; and for chained models the full one-step Jacobian of (prediction, memory) at steps 1, 25, 50: spectral radius, Henrici's departure from normality, and their defect. In normalised units, so compare models with each other only.
- **Literature checked before writing the code.** Wake paper (2608.07189): 97–98% phase error, linear drift, post-hoc phase fix, a Long Short-Term Memory network only, no Mamba, certificate or control. Chung, Choi and Kim (2605.07755): affine recurrences (Mamba included) are neutral on the error subspace; recovery measured by pushing the memory and following the ratio of sizes; symbolic tasks only, no feedback of outputs; the Long Short-Term Memory network not tested. Pervez and Locatello (2605.08856): propagator J_{T-1}...J_0, normality defect ||J^T J - J J^T||_F, commutator penalty, computed with Jacobian-vector products.

## 19 October 2026 — Stage 2b follow-up (fixed before any Stage 2b result)

- **Why.** Stage 2's Stage 3 rule gave "neither pattern is clean". The numbers in details.json pointed elsewhere: the full Mamba's one-step mistakes do not cancel when added up (factor 6.8) while the Long Short-Term Memory network's do (3.3). That inference assumed equal-sized mistakes along the horizon, so it is checked directly.
- **C1** step-to-step correlation of one-step mistakes (prediction: full Mamba at least 0.10 higher than the Long Short-Term Memory network, chained training). **C2** accumulation factor of the timing and shape parts separately (prediction: timing larger for the full Mamba). **C3** one-step clock on the true zero-input loop, plus how often the training input is near zero (no prediction; rule: ≤ 0.90 slow on every step, ≥ 0.97 slowness created by feedback).
- Config `configs/analysis/stage2b_followup.yaml`, tool `tools/diagnose_followup.py`, calculations added to `src/evaluation/error_diagnosis.py`.
